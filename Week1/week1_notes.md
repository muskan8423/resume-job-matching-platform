# Week 1 – Pandas Basics

## Project

Resume Job Matching Platform

## Topics Learned

### 1. Pandas

Pandas is a Python library used for data manipulation and data analysis.

### 2. Dataset

The project uses a sample resume dataset containing:

* Name
* Skills
* Experience
* Education
* Job Role

### 3. Features

Features are the input values used by the system.

For this project, the features are:

* Skills
* Experience
* Education

### 4. Labels

A label is the target/output value.

For this project, `Job_Role` is considered the label.

### 5. Pandas Operations Practiced

The following operations were performed:

* Load CSV file
* Display first rows using `head()`
* Check dataset shape using `shape`
* Check columns using `columns`
* Check data types using `dtypes`
* Check missing values using `isnull()`
* Check duplicate rows using `duplicated()`
* Remove duplicates
* Fill missing values
* Save cleaned dataset

### 6. Data Cleaning

Duplicate records were removed and missing values were filled with `"Not Specified"`.

The cleaned data was saved as:

`cleaned_dataset.csv`

## Week 1 Outcome

By completing Week 1, I learned the basics of Pandas and how to load, explore, and clean a sample resume dataset.

I also learned the difference between features and labels and how they will be used in the future stages of the Resume Job Matching Platform.
